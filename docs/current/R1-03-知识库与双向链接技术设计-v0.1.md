## 一、目标与边界

本任务在现有纯文本笔记基础上建立可靠的笔记双向链接，不引入富文本编辑器或图谱。

本任务包含：

- 解析 `[[笔记标题]]` 精确链接。
- 输入 `[[` 时提供现有知识笔记自动补全。
- 对重名笔记要求用户选择目标，并写入确定性 ID。
- 笔记内容和正向链接记录在同一 SQLite 事务中保存。
- 在笔记编辑详情中展示“链接到”和“被引用”。

本任务不包含：

- 富文本、图谱、附件链接和跨实体（任务/项目/目标）链接编辑。
- 自动修复标题改名或已删除目标的链接文本。
- 按链接关系筛选搜索结果。

## 二、链接语法与解析

### 2.1 标准链接

当标题唯一时，使用：

```text
[[数据库索引]]
```

系统仅在当前活动知识笔记中找到唯一同名标题时建立关联。

### 2.2 重名笔记

如果存在同名笔记，系统不会猜测目标，而是要求从自动补全中选择。选择后写入带 ID 的确定性语法：

```text
[[性能优化|42]]
```

这保留可读标题，同时避免标题重复或后续重名造成关联漂移。

### 2.3 未匹配和失效链接

- 未匹配或歧义链接保留在正文中，但不会写入 `note_links`。
- 编辑器显示提示，用户可继续保存，之后再补建目标笔记或从候选中选择。
- 目标笔记被软删除后，既有记录仍保留；详情显示为“已删除”，不会导致页面崩溃。

## 三、原子保存与展示

`save_knowledge_note` Rust 命令在单个事务中执行：创建或更新知识笔记、验证所有目标笔记、删除旧正向链接、写入去重后的新链接并提交。缺失目标、自链接或任一步失败都会回滚。

笔记编辑弹窗同时显示：

- **链接到**：当前笔记引用的可用笔记或已删除目标提示。
- **被引用**：其他活动知识笔记对当前笔记的引用。

所有链接项均可跳转并打开目标笔记编辑状态。
