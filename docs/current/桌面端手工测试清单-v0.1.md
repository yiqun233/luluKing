# 桌面端手工测试清单（v0.1）

> 用途：发布前在真实 Windows 桌面环境完成自动化测试无法替代的验收。
> 适用版本：`0.3.0` 及以后

---

## 一、执行规则

- 每次候选发布至少在一个非开发数据目录中执行一次；涉及迁移或安装升级时使用一份可恢复的副本数据。
- 任一“阻断”项失败，停止发布并保留日志、安装包版本和复现步骤。
- 通过项记录日期、应用版本、执行人和环境；不要以开发者工具中的成功日志替代实际操作。

## 二、启动、权限与离线

| 项目 | 操作 | 预期 | 级别 |
|---|---|---|---|
| 首次启动 | 安装后首次启动应用 | 正常显示仪表盘，无白屏或权限报错 | 阻断 |
| 既有数据库 | 使用上一版本数据目录启动 | 数据库自动迁移，任务/笔记/计划均可读取 | 阻断 |
| CSP 与能力 | 打开设置、备份、恢复预览、任务编辑 | 不出现 capability 或 CSP 拒绝错误 | 阻断 |
| 离线使用 | 断网后完成任务、创建笔记、浏览页面 | 本地功能正常；AI 显示可理解的失败提示 | 高 |
| AI 地址校验 | 输入 HTTP、localhost 或非 443 地址并保存 | 拒绝保存且不暴露 API Key | 高 |

## 三、核心流程与关联

| 项目 | 操作 | 预期 | 级别 |
|---|---|---|---|
| 任务 | 新建、编辑、完成、批量安排/删除任务 | 列表及仪表盘同步刷新；删除需确认 | 阻断 |
| 收件箱 | 新建收件箱笔记并升级为知识 | 成功后才关闭升级弹窗，标题/主题保存正确 | 高 |
| 搜索与标签 | 用关键词、`type:`、`tag:`、`status:` 搜索并打开结果 | 返回正确实体，可跳转编辑 | 高 |
| 双向链接 | 保存 `[[笔记标题]]` 链接后查看正反向关系 | 链接关系同步，歧义不会自动误链 | 高 |
| 周计划复盘 | 选择承诺任务，在复盘中分别完成、顺延、回待办池、放弃 | 统计与任务去向一致；顺延任务进入已有下周计划 | 阻断 |

## 四、备份、恢复与安装升级

| 项目 | 操作 | 预期 | 级别 |
|---|---|---|---|
| 备份 | 设置页创建备份并查看最近备份 | 文件生成，数量与当前数据相符，不含 API Key | 阻断 |
| 恢复预览 | 选择有效、损坏和旧格式备份 | 有效备份可预览；无效文件不写入数据 | 阻断 |
| 原子恢复 | 恢复一份已验证备份后重启应用 | 数据与关联正确；失败时当前数据未被修改且有安全备份 | 阻断 |
| 升级安装 | 在含数据旧版本上安装新版本 | 保留用户数据、自动迁移并可正常启动 | 阻断 |
| 卸载重装 | 卸载后确认数据目录仍在，再安装相同版本 | 用户数据保留，应用可读取 | 高 |

## 五、性能冒烟

| 项目 | 操作 | 预期 | 级别 |
|---|---|---|---|
| 路由加载 | 冷启动后依次打开知识库、搜索、设置、复盘 | 首次可见加载提示短暂出现，页面最终正常，无空白或错误 | 高 |
| 大列表 | 导入/创建数百条任务与笔记后滚动列表、执行搜索 | 滚动和搜索保持可用，无明显持续卡顿 | 高 |
