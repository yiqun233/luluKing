# R2-03：测试与交付流水线技术设计（v0.1）

> 状态：代码完成，CI 与桌面端烟测待执行
>
> 所属阶段：R2 工程化与安全收口
>
> 日期：2026-08-25

---

## 一、实现

- 新增 `typecheck`、`test:rust` 与 `verify` 命令；`verify` 依次执行 Vitest、类型检查与生产构建、Rust 测试。
- 新增 Windows GitHub Actions 工作流，在每个 push 和 pull request 上执行 `npm ci` 与 `npm run verify`。
- 补充收件箱升级和任务批量操作组件测试；收件箱升级调整为仅在成功后关闭弹窗，失败时保留输入。
- 新增桌面端手工测试清单，覆盖启动、迁移、权限、离线、AI 失败、备份恢复、升级安装、R1 关联闭环与性能冒烟。

## 二、边界

- CI 先执行与本地一致的类型检查、前端测试、生产构建和 Rust 测试；尚不在 CI 生成/上传 NSIS 安装包，待真实 Windows 发布机的打包与基础启动验证稳定后再接入。
- 工作流进入远程仓库后才会真正运行；本地已可通过 `npm run verify` 获得等价检查。
