# 数据备份与恢复说明（v0.1）

> 适用版本：应用 `0.1.0`、数据库迁移版本 1–5
>
> 更新日期：2026-08-25

---

## 恢复前必须知道

- 恢复是全量覆盖，不支持合并、选择性恢复或撤销。
- 点击恢复后，应用会先自动备份当前业务数据；恢复失败时当前业务数据不会被修改。
- 备份不包含附件、AI 设置和 API Key。
- 只要当前数据库已有附件记录，恢复会被拒绝，避免附件文件与数据库记录脱节。

## 创建备份

1. 打开“设置 → 数据备份”。
2. 点击“立即备份”，等待出现成功提示。
3. 在同一区域确认“最近备份”时间已更新。

备份文件位于 `%APPDATA%\com.yi.luluKing\luluKing\backups\`，文件名以 `luluKing-backup-` 开头。请将重要备份复制到另一块磁盘或可信的离线位置。

## 恢复备份

1. 关闭正在编辑的重要表单，打开“设置 → 数据备份”。
2. 点击“从备份恢复”，选择 JSON 备份文件。
3. 核对预览中的文件名、导出时间、来源版本和记录数量。
4. 点击“创建安全备份并恢复”，不要在恢复完成前关闭应用。
5. 应用重新加载后，检查任务、笔记、标签、周计划承诺和复盘是否符合预期。

## 常见情况

| 情况 | 处理方式 |
|---|---|
| 文件无法预览 | 文件可能损坏、格式不受支持或缺少必要关系；不会写入数据库。换用另一份备份。 |
| 恢复被附件限制拒绝 | 当前格式不含附件。保留现有数据和附件，等待附件备份功能；不要手动删除 `files` 表记录来绕过限制。 |
| 恢复失败 | 当前数据保持不变，且自动安全备份已生成。记录错误提示后重试或使用该安全备份恢复。 |
| 误恢复了旧数据 | 选择恢复前自动创建的安全备份，再按上述流程恢复。 |
| 需要彻底清理应用数据 | 先创建并另存备份，再卸载应用后手动删除 `%APPDATA%\com.yi.luluKing\`。这一步不可恢复。 |

## 发布或升级前建议

- 先创建一份备份并确认可预览。
- 安装新版本后检查“最近备份”、任务列表和知识库是否可用。
- 按《桌面端手工测试清单》完成迁移、恢复和升级安装项目。
