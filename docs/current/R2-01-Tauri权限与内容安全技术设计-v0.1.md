## 一、目标

在不影响本地数据库、备份恢复和 AI 复盘流程的前提下，收紧桌面端的 CSP、Tauri capability 与原生插件依赖。

## 二、设计与实现

- CSP 仅允许应用自身脚本、受控的内联样式、应用资源/data 图片以及 Tauri IPC；禁止对象嵌入、外部脚本和网页直接访问网络。
- 主窗口仅保留应用版本读取、SQLite 读写、AI 设置所需的 Store API 和 HTTP 插件调用权限。
- 文件系统权限限定为 `$APPDATA/luluKing/**` 的备份和新附件目录；为兼容已存在的旧附件记录，读取/删除额外允许 `$APPDATA/files/**`。
- 移除未使用的 opener 插件及其前后端依赖，避免应用任意打开 URL、路径或文件管理器。
- AI Base URL 仅允许无认证信息、无查询参数的标准 HTTPS 443 端点；显式拒绝 HTTP、localhost、IPv6 loopback 和自定义端口。本地模型支持将在后续以独立、可审计的策略评估。

## 三、已知边界

- API Key 不进入业务备份、页面不回显完整值，且不会出现在错误提示中；当前仍由 Tauri Store 保存。迁移至操作系统凭据存储属于后续安全收口项，不能将当前存储方式描述为系统级密钥库。
- 本轮尚未进行可见桌面端手工烟测；已完成 capability/CSP 编译校验、前端全量测试、生产构建和 Rust 测试。
