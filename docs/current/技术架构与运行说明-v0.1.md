# luluKing 技术架构与运行说明（v0.1）

> 文档性质：当前实现的技术事实基线
>
> 日期：2026-08-25
>
> 适用版本：应用 `0.1.0`、数据库迁移版本 `5`

---

## 一、运行结构

```text
React 19 页面 / 组件
        │
TanStack Query Hooks ── Repository ── tauri-plugin-sql ── SQLite app.db
        │                                      │
        │                                      ├─ FTS5 与同步触发器
        │                                      └─ 001–005 有序迁移
        │
Tauri IPC ── Rust 原子命令（恢复、笔记链接、标签合并、计划承诺）
        │
Windows 应用数据目录 / 受限文件系统 / HTTPS AI HTTP 插件
```

## 二、技术选型

| 层 | 当前实现 |
|---|---|
| 桌面端 | Tauri 2、Rust、NSIS 当前用户安装包 |
| 前端 | React 19、TypeScript、Vite、Tailwind CSS、React Router HashRouter |
| 数据状态 | TanStack Query；局部 UI 状态使用 React state/context，不使用 Zustand |
| 数据库 | SQLite（`tauri-plugin-sql`）、Repository 层、FTS5 |
| AI | `tauri-plugin-http` 调用 OpenAI 兼容接口；`tauri-plugin-store` 保存设置 |
| 测试与交付 | Vitest、Rust `cargo test`、Windows GitHub Actions、本地 `npm run verify` |

当前未引入 Tiptap、dnd-kit、虚拟列表或同步服务。知识编辑为纯文本；双向链接使用 `[[标题]]` 与 `[[标题|id]]` 语法。周计划使用选择式承诺，不使用拖拽。

## 三、数据与迁移

- 应用数据库为 `%APPDATA%\com.yi.luluKing\app.db`。
- 已注册迁移：`001_initial`、`002_migration_baseline`、`003_search_indexes`、`004_search_fts`、`005_plan_commitments`。
- 新发布版本只能新增迁移，不能改写已发布迁移的业务语义。
- FTS5 覆盖任务、笔记、项目、目标、习惯、日程、复盘和标签；触发器负责新增、更新与软删除同步。
- `plan_tasks` 将周计划任务与复盘去向关联，决策和顺延由 Rust 事务完成。

## 四、备份与恢复

- 备份格式为 `luluKing-backup` v1，当前接受数据库版本 1–5；旧备份缺少 `plan_tasks` 时按空数组兼容。
- 备份包含业务表与软删除记录，不包含附件二进制文件、AI 配置或 API Key。
- 恢复先创建自动安全备份，再经 Rust 单事务校验并写入；任一步失败不会改写当前业务数据。
- 若当前数据库存在附件记录，恢复会安全拒绝，因为当前备份格式不含附件。详细操作见《恢复说明》。

## 五、安全边界

- CSP 只允许应用资源、受控内联样式和 Tauri IPC；不允许外部脚本、对象嵌入或页面直接发起网络请求。
- capability 仅开放应用版本、SQLite、必要 Store 操作、备份/附件目录和标准 HTTPS AI 请求；未使用的 opener 插件已移除。
- AI 地址必须为不含认证信息、查询参数或片段的 HTTPS 标准端口地址；HTTP、localhost 与自定义端口会被拒绝。
- API Key 不进入备份、界面不回显完整值，也不应写入日志；当前仍存于 Tauri Store，尚未迁移至操作系统凭据库。

## 六、性能与交付

- 仪表盘与任务页保留在首屏；11 个低频页面和任务编辑器按需加载，导航意图会预取目标页面。
- 生产构建主入口为 442.26 KB（gzip 139.04 KB）；任务与知识列表使用 `content-visibility` 跳过视口外渲染。
- 本地合并前执行 `npm run verify`；远程 push/pull request 使用 Windows GitHub Actions 执行同一验证。

## 七、已知限制

1. 附件未进入备份数据包，存在附件记录时不允许恢复。
2. API Key 尚未进入系统级密钥库。
3. Windows 干净环境、真实旧版本升级与收紧 capability 后的可见桌面端烟测仍需按《桌面端手工测试清单》执行。
4. CI 当前不生成或上传 NSIS 安装包；代码签名、打包 CI 与基础启动验证后续再接入。
