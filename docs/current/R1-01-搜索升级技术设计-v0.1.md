## 一、目标与边界

本任务让用户可以跨主要业务实体搜索、筛选并直接进入后续操作，不再局限于任务、笔记、项目和目标的基础 `LIKE` 查询。

本任务包含：

- 验证实际 Tauri SQLite 运行时的 FTS5 能力。
- 搜索任务、笔记、项目、目标、习惯、日程、复盘和标签。
- 支持 `type:`、`tag:`、`status:` 三种最小筛选语法。
- 结果按类型分组，展示上下文，并使用 URL 参数打开对应编辑状态。
- 为 FTS 索引同步和千条级检索建立自动化回归。

本任务不包含：

- 搜索结果高亮、拼音检索、自然语言查询和复杂布尔表达式。
- 标签的跨实体详情页；标签结果暂时跳转到现有任务标签切片，完整切片能力属于 R1.2。
- 富文本、附件内容或 AI 配置检索。

## 二、技术决策

### 2.1 FTS5 可用性

在与桌面端相同的 Rust `sqlx` SQLite 运行时中，`CREATE VIRTUAL TABLE ... USING fts5` 测试通过，因此采用 FTS5 主索引，而非继续使用纯 `LIKE` 方案。

数据库升级链路：

- `003_search_indexes.sql`：为状态、标题和标签关联筛选增加普通索引。
- `004_search_fts.sql`：创建 `search_fts` 虚拟表、回填已有业务数据，并为八类实体创建插入、更新、删除同步触发器。
- 当前数据库版本提升至 `4`；备份与恢复校验同步接受版本 `1` 至 `4`。

### 2.2 中文检索策略

FTS 的 `unicode61` 分词会把连续中文文本视为完整词元。搜索查询将输入中的字母和数字词元转换为安全的前缀匹配，例如“性能”转换为 `性能*`，保证“性能”可命中“性能任务”。特殊字符不会进入 FTS 表达式，避免查询语法错误。

### 2.3 筛选语法

| 语法 | 示例 | 行为 |
|---|---|---|
| `type:` | `type:任务 性能` | 仅搜索指定实体类型；支持中文和英文类型名。 |
| `tag:` | `tag:性能 缓存` | 仅返回关联指定活动标签的实体。 |
| `status:` | `status:未完成 缓存` | 按实体状态筛选；例如未完成、已完成、进行中、已归档、草稿。 |

无法识别的筛选词保留为普通关键词。每类实体最多返回 20 条，避免输入时读取无上限结果集。

## 三、交互与导航

- 搜索结果按实体类型分组，显示状态、日期、摘要或类型等上下文。
- 任务、笔记、项目、目标、习惯、日程和复盘使用 `?open=<id>` 打开对应编辑状态。
- 收件箱笔记跳转到收件箱的现有升级入口。
- 日程结果同时携带日期，跳转后切换到该日期并打开事件。
- 标签结果使用 `?tag=<id>` 跳转到任务页已有标签切片。
