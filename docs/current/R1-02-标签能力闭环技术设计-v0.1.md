## 一、目标与边界

本任务将标签从任务、笔记中的局部属性升级为可跨实体查看和整理的横向维度。

本任务包含：

- 在任务、项目、目标、笔记、习惯、复盘和日程编辑中维护标签。
- 新增标签管理页，查看一个标签关联的七类业务实体，并按类型筛选。
- 支持创建、改名、归档、恢复和同义标签合并。
- 定义不物理删除的标签策略，保护历史关联。

本任务不包含：

- 标签颜色编辑、层级标签、同义词自动识别。
- 标签的跨实体统计图表或批量编辑。
- 已归档标签的重新自动分配。

## 二、交互与数据策略

### 2.1 编辑入口

`TagSelector` 只展示活动标签，并支持输入创建。编辑弹窗在业务实体保存成功后再更新标签关联，避免实体写入失败时覆盖既有标签。

### 2.2 标签切片

`/tags` 页面显示活动和已归档标签。选择一个标签后，可查看并按以下类型筛选关联内容：任务、项目、目标、笔记、习惯、日程、复盘。每条内容均可跳转到对应页面并打开编辑状态。

### 2.3 删除与归档

标签默认不提供物理删除入口：

- 无论是否存在关联，均可归档；归档后不会出现在新的标签选择器中。
- 归档不会删除既有 `taggables` 记录。
- 已归档标签可以恢复为活动状态。
- 有关联的标签会在归档确认框中显示关联数量，并提示合并是替代方案。

### 2.4 合并事务

合并通过 Rust `merge_tags` 命令在单一 SQLite 事务中执行：

1. 校验来源标签和目标活动标签。
2. 将来源标签关联复制到目标标签，使用 `INSERT OR IGNORE` 去除重复关联。
3. 删除来源标签关联。
4. 归档来源标签。
5. 提交事务；任一步失败会回滚。
